- Debido a que la aplicación se encuentra en entorno de desarrollo y no ha sido sometida al proceso de verificación oficial 
de Google (el cual puede extenderse por más de 3 meses), el acceso está limitado por políticas de seguridad de Google 
Cloud. Por tanto, para probar el inicio de sesión o la importación, es estrictamente necesario que el correo electrónico 
del usuario esté registrado previamente en la lista de "Usuarios de prueba" en la Google Cloud Console. Sin esta 
configuración previa, el sistema denegará el acceso al token de autenticación por motivos de seguridad.
